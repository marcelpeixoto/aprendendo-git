# 🚀 Trilhas de Aprendizado em Engenharia de Software (Python)

Bem-vindo(a) ao meu repositório de evolução em desenvolvimento de software! Este espaço foi criado para consolidar meus estudos em lógica de programação, boas práticas de mercado, arquitetura de código e persistência de dados utilizando **Python**.

Aqui estão documentados os meus primeiros passos práticos, estruturados de forma incremental, simulando o fluxo de trabalho e os padrões exigidos no mercado de tecnologia.

---

## 📂 Estrutura do Repositório

O repositório está dividido em etapas que refletem a minha evolução técnica:

### 1. [📂 FirstCode](./FirstCode)
* **Foco:** O Primeiro Passo (O Batismo do Dev).
* **O que foi desenvolvido:** O clássico script `Hello World`.
* **Objetivo:** Quebrar o gelo com a linguagem Python, garantir a configuração inicial do ambiente de desenvolvimento e realizar o primeiro commit bem-sucedido via Git. Todo grande projeto começa com uma única linha de código.

### 2. [📂 FirstProject - Sistema de Cadastro de Alunos](./FirstProject)
* **Foco:** Engenharia de Software, Resiliência de Código e Persistência.
* **O que foi desenvolvido:** Um sistema de console completo para gerenciamento de alunos com cálculo automático de métricas (médias de notas).
* **Conceitos Avançados Aplicados:**
  * **Tratamento de Exceções (`try/except`):** Código blindado contra quebras inesperadas causadas por entradas inválidas do usuário (`ValueError`, `JSONDecodeError`).
  * **Encapsulamento e Modularização:** Isolamento de lógicas complexas de validação em funções reutilizáveis, mantendo o fluxo do menu principal limpo e legível (Princípio DRY).
  * **Persistência de Dados (JSON):** Manipulação de leitura e escrita de arquivos locais utilizando a biblioteca nativa `json`.
  * **Caminhos Dinâmicos (Multiplataforma):** Uso da biblioteca `os` para mapeamento de diretórios em tempo de execução, garantindo que o software funcione perfeitamente em Windows, Mac ou Linux.
